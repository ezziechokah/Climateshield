# Meeting Notes Archive

## Purpose

Archive of meeting notes using [`docs/templates/meeting_notes_template.md`](../templates/meeting_notes_template.md), preserving decision history that feeds [`docs/37_Project_Change_Log.md`](../37_Project_Change_Log.md) and [`docs/18_Risk_Assessment.md`](../18_Risk_Assessment.md).

> Version: 1.0 | Author: ClimateShield Nexus Program Management | Last Updated: 2026-07-27

## Naming Convention

`YYYY-MM-DD-<meeting-type>.md`, e.g., `2026-08-10-sprint-planning.md`, `2026-08-14-architecture-sync.md`.
