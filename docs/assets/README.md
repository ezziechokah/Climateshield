# Assets

## Purpose

The specification for every visual asset ClimateShield Nexus requires ([01_Asset_Manifest.md](01_Asset_Manifest.md)), plus — once produced — the static asset files themselves (logos, photographs, exported PDFs, screenshots) for cases where an image is more appropriate than an inline Mermaid diagram.

> Version: 1.1 | Author: ClimateShield Nexus UI/UX Team | Last Updated: 2026-07-27

## Contents

| Document | Purpose |
|---|---|
| [01_Asset_Manifest.md](01_Asset_Manifest.md) | Complete icon/illustration/logo/favicon specification — no image files produced yet, this is the binding spec for producing them |

## Conventions

- Prefer inline Mermaid diagrams in the owning document wherever possible (version-controlled, diffable) — see [`docs/diagrams/README.md`](../diagrams/README.md).
- Use this folder for genuinely static assets once produced: logos, photographs, exported PDFs for non-technical audiences, screenshots once the UI exists — all per the specifications in [01_Asset_Manifest.md](01_Asset_Manifest.md).
- Large binary assets (>5MB) should be referenced via external links (e.g., a design-team asset library) rather than committed, to keep the repository lightweight.
